# 交接说明

## 当前进度

完成 `autonomous/ground_avoidance` 避障算法的安全修复（对应 `.ai/DECISIONS.md` 的 D001）。

审查避障算法时通过数值实验确认了若干缺陷，本次修复了其中属于安全约束的部分：

1. **正前方深度缺测时满速前进**（最严重）：修复前中心扇区无有效深度、两侧 6 米时输出 `D,750,750`，
   且不报障碍。现改为判定为未知并按危险停车，输出 `S`，原因显示"正前方深度无效，停车待确认"。
2. **没有渐进减速，只有悬崖式急停**：修复前推力只在 0.75 / 0.65 / 0 三档跳变，
   原因是 `default_forward_throttle` 下限把减速后的速度又抬了回去。现改为从 1.8 米到 0.6 米线性减速，
   已用测试验证单调性。
3. **侧向避让饱和后不加转向**：修复前右侧障碍从 0.8 米逼近到 0.25 米，输出恒为 `D,482,1000`。
   现改为转向上限随最近障碍距离放宽，实测从 `-0.011` 递增到 `-0.250`。
4. **深度有效性二值化**：新增有效像素占比门槛（`min_valid_ratio=0.15`），
   避免少量"很远的散点"把危险扇区洗成通畅；普遍超量程视为"很远"而非未知。
5. **转向平滑被关闭**：`steering_smoothing` 由 1.0 恢复为 0.25，并补充测试验证摆动被抑制。
6. **固定左偏置**：左右信息相同或都未知时改为沿用上一次转向方向，不再无脑左转。

修复过程中自己引入并修正的一个问题：最初用 `throttle × 比例` 表达转向放宽，
在 0.6 米停车边界上因 float32 精度使 `throttle` 为极小正数，导致转向被压成 0
（既不前进也不转向）。改用"巡航上限与最大转向之间按距离平滑插值"后解决。

## 修正实地反馈：转向过大错过出口（2026-09-14）

用户反馈“检测到障碍会转向，但转得太大，会错过出口”。定位后发现这是上一轮修改
（D001 的“近距放宽转向”）**自己引入的回归**，不是原始算法的问题。

根因：`_steering_limit` 在障碍物近于 `obstacle_distance_m` 时把转向上限放开到
`max_steering=1.0` 且不乘 throttle。`throttle=0.65` 配 `steering=1.0` 时内侧车轮成为
负值（0.65-1.0=-0.35），车辆“边前进边原地甩头”，转向弧度远超需要，因此转过头错过开口。

修正（详见 DECISIONS 的 D003）：

1. 行驶中转向上限始终 `= throttle × 比例`，比例在 0.35~1.0 之间按障碍距离插值；
   内侧车轮最多降到 0、绝不反转，避障变为“弯行”。
2. 原地转向只在正前方被堵（停车）时允许，且幅度限制为 `pivot_steering_limit=0.60`
   而非满舵，避免在狭小空间旋转过快。
3. 转向平滑之后**再限制一次**：修正了平滑在限制之后执行导致油门骤降时残留转向超限的问题
   （真实数据实测 31/80 帧内轮反转）。
4. 新增 `turn_switch_margin_m=0.15`，避免开口处左右反复；正前方判断加 5 毫米容差消除死点。

验证方式（都是离线数值验证 + 只读相机，未驱动硬件）：

- 相机真实数据：内轮反转帧数 31 -> 0；原地转向指令 `D,1000,-1000` -> `D,600,-600`。
- 运动学仿真（走廊 + 障碍 + 侧面开口）：开口 0.6 米时旧行为有 106 帧内轮反转、
  `|steering|/throttle` 最高 5.38，新行为 0 帧反转、比值 ≤1.00；开口 ≥0.6 米两版都能通过，
  0.5 米时两版都碰撞（当前无显式路径生成，窄开口对准需 follow-the-gap / VFH+）。
- 单测由 17 增至 21 个，新增“行驶中内轮不反转”“原地转向仅限停车”“平滑跨帧仍受限”“方向切换余量”。

仿真脚本目前只放在机器人 `/tmp` 临时目录，未入库；TODO 中已记录建议把它整理进 `tests/`。
本轮**未做新的实车测试**（现场有人在测试场地内，不适合开动车辆）。

## VLM 视觉导航模块（2026-09-18，已完成编码与离线验证）

新增模块 `autonomous/vlm_navigation`：用视觉大模型驱动地面车闭环行驶，

默认目标是向前行进并探索周围环境。只控制地面车，不涉及 PX4 与飞行。

**模块内容**：

  时钟与 sleep 可注入，测试用假时钟不真实等待。

- `navigation_loop.py`：主循环编排，含图片上下文滑窗、只回文字的停滞保护、

## 运行注意事项

- 独立模式必须走启动脚本 `./scripts/start_ground_avoidance.sh`：直接 `python3 run_ground_avoidance.py`
  会因缺少 pyserial（它在 `flydrive-env` 里）而失败。同理网络控制模块也要用它的启动脚本。
- 测试时建议用 `timeout -s INT -k 3 N` 限定秒数，让程序的 `finally` 执行停车；结束后可再显式补发一次 `S`。

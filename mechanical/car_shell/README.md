# car_shell：陆空两栖机器人小车外壳

本模块用 Blender 脚本参数化生成小车外壳 3D 模型，采用「一体式主壳体 + 独立后部滑盖」结构。
除滑盖外的整个车身外壳是一个连续的一体化零件，不做上下壳分体。

## 一、产出对象

| 对象 | 说明 |
|---|---|
| `main_shell` | 一体式主壳体。含左右半包覆轮罩、后部设备舱、顶部维护开口、滑槽、内部安装特征与走线结构。 |
| `rear_sliding_cover` | 后部滑盖。独立零件，内嵌于设备舱顶部，与车顶齐平，沿前后方向滑动，可从车尾完全抽出。 |

另有占位模型（`ph_wheel_*`、`ph_motor_*`、`ph_battery`、`ph_jetson`、`ph_caster`）只用于
干涉与空间校核，保存在 `car_shell_assembly.blend` 与剖视渲染图中，**不属于最终外壳**，
导出 STL 前会被自动移除。

## 三、设计尺寸推导（为什么是这个尺寸）

任务书给定的是轮径、单侧轮+电机长度、电池和主控型号、后部从动轮尺寸，
其余整体外形尺寸需要自行确定。关键约束与取舍如下：

1. **车底离地高度 33**：由后部从动轮决定。从动轮的「固定底座到地面」为 33 mm，
   底座贴在车体底面上，因此车底必须正好在 33 mm 高处，从动轮才能触地而车体水平。
   这个高度同时让前轮露出 33 / 65 = **50.8%**，正好满足「包覆上半部分、下半部分
   露出」的半包覆轮罩要求——两个独立约束指向了同一个高度。
2. **宽度 210**：单侧「车轮 + 电机」总长 95 由轮外缘向内占用，两侧共 190。
   若车身只有 190，两台电机将在中心直接相碰、不留任何中间结构，因此在中心留出
   20 mm 用于隔墙与线材，取 210。
3. **车体高 74**：轮舱顶面在 z = 33 + 32.5 + 37.5 = 103，车顶必须在其上；同时
   设备舱要容纳叠加放置的电池（27）与 Jetson（35）并留操作余量，故车顶取
   z = 107（车体高 74）。此时设备舱净高 66，叠加所需 63，余量 3 mm。
4. **长度 305**：前端容纳轮舱（轮心 x=100），中部容纳 150 mm 长电池，
   尾部掏空，底板内侧局部加厚出一圈从动轮安装垫。
5. **电池布置**：电池平放在舱底，后端由舱内后壁限位、前端由挡边限位；Jetson 由
   两条纵向导轨托到电池上方，两者沿高度叠加，最大化利用舱内空间。
6. **轮罩内侧壁略低于车底（3.5 mm）**：电机与车轮同轴，电机固定螺丝孔位于半轴
   高度 32.5 mm，比车底 33 mm 低 0.5 mm。为了让螺丝孔周围有材料，轮罩内侧壁
   （同时是电机安装板）向下延伸 3.5 mm。这是「车底高度由从动轮决定」与
   「电机螺丝孔必须与轮轴同轴」两条约束叠加的必然结果。

## 四之二、后部从动轮安装方式

从动轮底座是**从下方贴到车体底板上、用 4 颗 M3 螺丝向上拧紧**的，固定面就是底板
外表面（z=33）。底板本身只有 2.5 mm，太薄无法可靠受螺，因此在底板**内侧**局部加厚出
一圈安装垫（前后 36 mm、左右 46 mm、高 5 mm）：

- **安装垫**只在腔体底部隆起 5 mm，**底面保持平整**，不影响底座贴合；
  垫子上方是空腔，装配时不挡手（早期版本曾做成从底板贯通到顶盖板的高柱，反而阻碍安装，
  已废弃）。
- **通孔**：Ø3.4（M3 间隙），从底板底面贯通到安装垫顶面，长 7.5 mm。
- **受力厚度**：底板 2.5 + 安装垫 5.0 = **7.5 mm**，M3 螺丝可直接可靠锁紧。
- **所需螺丝**：约 **M3 × 14**（受力厚度 7.5 + 底座板厚 3 + 余量 4），是普通短螺丝，
  不再需要早期版本那种 M3 × 80 的长螺丝与顶部螺母。
- **密封性**：四个孔只贯穿底板与安装垫，其上方是车尾空腔、不连通设备舱，
  因此不会成为水汽与灰尘进入电子舱的通道。

## 五、运行方式

生成脚本：`build_car_shell.py`（Blender 无头运行，一次生成全部产物）。

```bash
cd /home/molate/Projects/AmphibiousRobot/CONTROL/mechanical/car_shell
blender --background --factory-startup --python build_car_shell.py
```

脚本会依次：建模 → 尺寸与结构校核 → 渲染预览图 → 导出 STL 与 .blend。
若校核不通过，脚本以退出码 2 结束并打印不满足项。

### 本机 Blender 缺库的处理

本机 Blender 5.2.1 需要 `libjsoncpp.so.27`，而系统 jsoncpp 1.9.6 只提供 `.so.26`，
直接运行会报缺库。无需改动系统，下载 jsoncpp 1.9.8 后解压到用户目录并用
`LD_LIBRARY_PATH` 指向即可：

```bash
curl -fsSL -o /tmp/jsoncpp.pkg.tar.zst \
  https://geo.mirror.pkgbuild.com/extra/os/x86_64/jsoncpp-1.9.8-1-x86_64.pkg.tar.zst
mkdir -p ~/.local/blender-libs
tar --zstd -xf /tmp/jsoncpp.pkg.tar.zst -C ~/.local/blender-libs usr/lib/libjsoncpp.so.27 usr/lib/libjsoncpp.so

cd /home/molate/Projects/AmphibiousRobot/CONTROL/mechanical/car_shell
LD_LIBRARY_PATH=~/.local/blender-libs/usr/lib \
  blender --background --factory-startup --python build_car_shell.py
```

若执行 `sudo pacman -Syu` 把系统 jsoncpp 升级到 1.9.8，则无需上述临时目录。

## 七、脚本内置校核

脚本每次运行都会自动校核，全部通过才算成功（否则退出码 2）。校核分三类：

**1. 尺寸与间隙**：包围盒尺寸、轮子间隙、电机螺丝孔孔距与安装面位置、
单侧轮+电机总长、滑盖厚度与齐平度、滑槽尾端贯通、开口装载能力、舱内容积，
以及后部从动轮的孔距/底座高度/车底高度一致性/螺钉边距、前轮露出比例。

**2. 内部结构实体校验**：用 BVH 射线投射的奇偶判别逐点验证关键结构真的建出来了，
例如「电机安装隔板是实体」「螺丝孔是真通孔」「轮舱是空洞」「轮子上方是实体轮罩」
「轮罩内侧壁延伸到车底以下」「从动轮区域车底以下为空洞（脚轮可 360° 旋转）」。
这一步用于排除「隔板被轮舱切除」「孔钻在空气里」这类肉眼难以发现的错误。

**3. 装配干涉检查**：用 BVH 面片重叠检测验证滑盖与壳体、左右前轮与壳体、
电池/ Jetson/从动轮与壳体均为零重叠。

最近一次运行结果：主壳体 902 面、滑盖 64 面，均为单一连通块、非流形边 0，
37 项结构点校验与 6 项干涉检查全部通过（共 43 项）。其中从动轮四个孔逐个在
「底板内 / 垫下部 / 垫上部」三个高度各验证一次，确保是真通孔而非盲孔。

## 七之二、车尾掏空（材料优化）

早期版本把设备舱后壁停在 x=-100，车尾因此留下一整块 52.5 mm 厚的**实心**结构。
用实心点采样量化后发现：**该区域 100% 实心，占全机 46% 的材料，却只占 17% 车长**，
既厚重又浪费打印材料。

现在把设备舱一直延伸到车尾内壁（仅留 2.5 mm 尾壁），车尾全部掏空，只在底板内侧
加厚出一圈**从动轮安装垫**（前后 36 mm、左右 46 mm、高 5 mm）：

| 指标 | 修改前 | 修改后 |
|---|---|---|
| 车尾区材料体积 | 812.7 cm³ | 128.3 cm³ |
| 车尾区占全机材料 | 46% | 12% |
| 主壳体总材料 | 1773.1 cm³ | 1110.7 cm³ |
| 主壳体面数 | 996 | 902 |

整机材料减少约 **37%**。（中间一版曾用贯通到顶盖板的实心柱，材料为 1218.1 cm³；
后来按实际装配方式改为底板安装垫，进一步降到 1110.7 cm³。）

**注意**：从动轮的四个安装孔必须在安装垫**并集之后**再切（放在 `shell_holes()` 里），
否则安装垫会把 cavities 阶段切好的孔重新填实。这是本次改动踩到的坑。
## 八、关键实现注意事项

修改脚本时请留意两点，否则模型会被静默破坏：

1. **挖除体必须逐个单独做布尔求差**。把多个互相重叠的挖除体合并成一个网格再一次性
   求差会让 Blender 的 EXACT 求解器失败，实测会把壳体切成碎片或退化成薄板。
   请使用 `cut_many()`，不要合并。
2. **不要用 `object.bound_box` 量尺寸**。该缓存在布尔修改器应用后不会更新，读数
   不可信；请用 `mesh_bounds()`（直接读网格顶点）。

另外，几何构造要避免**平面相切**：例如从动轮让位圆柱若与设备舱后壁正好相切，
会产生非流形边。当前设计的从动轮底座以下部件全部位于车底之下，不需要让位凹槽，
从结构上绕开了这个问题。

3. **切除体的施加顺序**：任何挖除操作都必须放在它要切除的实体**被并集进去之后**。
   从动轮四个安装孔就是因为一开始放在 cavities 阶段（早于安装垫并集），结果被安装垫
   重新填实；移入 `shell_holes()` 后正常。新增切除特征时请先确认顺序。

## 九、需要按实物确认的推定尺寸

后部从动轮的**孔距（23 × 30）、底座到地面 33 mm、可 360° 旋转**均为用户给定，
已按给定值实现并进入校核。以下尺寸虽属同一部件或任务书未给出，仍按经验取值，
**上机前需按实物复核**，若有出入只需改 `build_car_shell.py` 顶部参数区并重新生成：

| 参数 | 当前取值 | 说明 |
|---|---|---|
| `CASTER_PLATE_X` / `CASTER_PLATE_Y` | 34 / 42 | 从动轮底座外形（须大于孔距 23 × 30）。影响车尾实心块深度与螺钉边距 |

| `WHEEL_WIDTH` | 25 | 车轮轴向宽度。影响轮心横向位置（`WHEEL_CY`） |
| `MOTOR_DIA` | 36 | 电机占位直径。影响电机腔能否容纳电机本体 |

| `JETSON` | 105 × 85 × 35 | Jetson Orin Nano 占位（含散热器高度）。载板实际为 100 × 79 |

从动轮底座由 4 颗 M3 螺丝固定，从动轮其余部分（旋转部与轮子）全部位于车底之下，
360° 旋转不会与车体干涉，因此车底不为从动轮开让位凹槽，后轮区域结构保持简单。

## 十、已知限制与后续可改进项

1. **轮罩内侧壁低于车底 3.5 mm**：电机螺丝孔与轮轴同轴（半轴高 32.5 mm），而车底由
   从动轮定在 33 mm，为了让螺丝孔周围有材料，轮罩内侧壁向下延伸 3.5 mm。这是两条
   约束叠加的必然结果，不影响行驶（该处远离地面）。若想与车底齐平，只能抬高车底
   （换更高的从动轮）或降低轮心。
2. **滑槽区域顶板已加厚**：滑槽底面到设备舱顶面之间的顶板净厚为 3.3 mm
   （`TOP_PLATE_T` 5.5 − 滑盖厚度 2.0 − 底面间隙 0.2），落在任务书建议的
   3~3.5 mm 区间内，满足滑轨/导向结构的局部加厚要求。
3. **未做真实装配仿真**：滑盖滑动为几何可用性推断（滑槽尾端开放、无阻挡），
   未做运动学仿真；实物建议先打印滑盖验证配合。
4. **未做强度/模态分析**：轮罩与车体连接处、顶板为大面积薄板，未做受力校核。
5. **未设计实际固定方案细节**：Jetson 为 4 个 M3 自攻底孔，未包含铜柱与螺柱选型；
   从动轮按"底座 4 孔直接拧到车底"设计，未包含螺母防松或加装金属嵌件。
6. **从动轮外形为推定**：给定的是孔距与底座高度，底座外形、轮径、拖尾为经验取值。
7. **前轮无转向机构**：按任务书要求，轮子不需要转向，因此未预留转向摆动空间；
   底盘转向依赖左右轮差速。
8. **产物追踪策略**：`.stl` 与 `.blend` 是模型本体，已纳入版本管理；`renders/` 下的
   预览图约 5 MB 且可由脚本一键重新生成，已在 `.gitignore` 中忽略。如需追踪预览图，
   删除 `.gitignore` 中对应行即可。
